Was ist lbDMF wxWidgets Dialog Blocks Codegenerator Compilation?

Dies ist ein neues Template, welches es Ihnen ermöglicht, lbDMF wxWidgets Dialog Blocks Anwendungen zu generieren. Verwendet wird dabei das lbDMF Framework und XRC Dialog Designs die in Dialog Blocks editierbar sind.

Dialog Blocks in Aktion: Hier sehen Sie ein Formular im Dialog Blocks Designer. Sämtliche Dialoge der Anwendung, die auf UML Designs basieren, sind generiert.

 

This is a new template, what allows you to create lbDMF wxWidgets Dialog Blocks applications. It uses the lbDMF framework und XRC dialog designs that you can edit in Dialog Blocks.

Dialog Blocks in action: Here you see a form in Dialog Blocks designer. All forms for the application, that are based on UML designs, are generated.
