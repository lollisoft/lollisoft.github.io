Was ist CAB Syncfusion Codegenerator Compilation?

Dies ist ein neues Template, welches es Ihnen ermöglicht, Syncfusion WinForms Anwendungen zu generieren. Verwendet wird dabei das Syncfusion Essential CAB Enabling Kit und ein ORM basiertes Datenbanksystem auf Sqlite basis verwendet.

CAB Syncfusion Codegenerator Compilation Anwendungen verwenden keine Logins und arbeiten lokal. Wenn Sie die lbDMF Manager Anwendung damit generieren, haben Sie eine lauffähige Anwendung, die die Modelldaten anzeigt.

 

This is a new template, what allows you to create Syncfusion WinForms applications. It uses the Syncfusion Essential CAB Enabling Kit and a ORM based database system using Sqlite.

CAB Syncfusion Codegenerator Compilation generated applications will not require logins and are working local. If you create the lbDMF Manager application, you will be able to view the model data in the running application.
